# TechNova-PC 🚀
**Interfaz moderna para la venta de componentes de computación y hardware.**

Este proyecto es una plataforma de e-commerce desarrollada para facilitar la visualización y compra de hardware especializado. Se enfoca en una experiencia de usuario fluida y un diseño responsivo.

## 🛠️ Tecnologías utilizadas
* **Frontend:** HTML5, CSS3 (Tailwind CSS) y JavaScript Vanilla.
* **Control de versiones:** Git y GitHub.
* **Despliegue:** GitHub Pages.

## 🌟 Características principales
* **Carrito de compras:** Funcionalidad para agregar y gestionar productos en tiempo real.
* **Diseño Responsivo:** Adaptado para dispositivos móviles, tablets y escritorio.
* **Catálogo dinámico:** Visualización organizada de productos y componentes.

## 📦 Instalación y uso
Si deseas ver el proyecto localmente:
1. Clona este repositorio: `git clone https://github.com/BJUNIOR26/TechNova-PC.git`
2. Abre el archivo `index.html` en tu navegador.
